# 做一间「会过日子的房间」

一张等距插画，加上时钟、天气和几个能点的地方，就能让一个角色「住」进去。

不需要建模，不需要美术基础，一天能做完一个最小版。

![模板效果](截图/模板效果.png)

## 看什么

| 文件 | 说明 |
|---|---|
| `index.html` | **攻略正文**（网页版，带目录）。直接双击打开，或者看线上版 |
| `攻略.md` | 同样内容的 Markdown，方便复制、二次编辑 |
| `模板/index.html` | **能直接跑的单文件模板**，双击就开：四时段 × 三天气、热区悬停、点击弹抽屉、标注模式 |
| `模板/sample-room.png` | 示例底图（换成你自己的等距图即可） |
| `截图/模板效果.png` | 模板跑起来长什么样 |

## 三步上手

1. 打开 `模板/index.html`，看看效果；
2. 把自己的等距房间图覆盖 `模板/sample-room.png`；
3. 打开 `模板/index.html?calib=1`（或者照攻略第 3 节）拖动热区，对到床、桌子、书架上。

## 攻略讲什么

- 先看效果、需要准备什么
- 三步做出最小版：底图 → 天色与天气 → 热区
- 三个可选升级：热区标注、灯与夜晚、让人物有状态
- 接进桌面客户端（iframe 怎么放、参数怎么传）
- 常见坑：改了像没改（缓存版本号）、坐标对不上（`getScreenCTM` 反算）、素材叠歪、换图不生效、中文文件被编辑器写坏、抽屉贴鼠标点不动
- 速通清单与文件结构

## 出处

这套做法来自「小鲸鱼房间」的实际制作过程：同一张图，白天和夜晚、晴天和雨雪，都是靠几层叠加和一点点状态切换做出来的，没有一张图是单独画的。

## 许可

随意取用、修改、再发布。

## 另一个版本：真 3D 的家（潮汐 / 大肥鱼）

同一个念头，另一条路：不用等距插画，直接用 Three.js 搭一个**能走进去、能转视角**的三维户型，
房间里的家具、窗、门、灯都是真的几何体，人物用桌宠的动画帧当化身，还能读她们的真实状态。

| 文件 | 说明 |
|---|---|
| `3d/index_home.html` | 能直接跑的单文件（约 1.1 MB，three.js 和贴图都内嵌，离线可用） |
| `3d/build_home_rich.py` | 生成器：改数据重跑就能重建 |
| `3d/whale-room-guide.md` | 3D 版的改房说明书（坐标、家具格式、踩坑） |
| `3d/房间-姐姐.json` / `3d/房间-鲸鲸.json` | 两个人各自的房间家具清单，各改各的 |

**3D 版多出来的东西**：俯视 / 第一人称走动（WASD，带墙体碰撞）/ 深海发光生物小游戏 / WebAudio 海浪声 /
桌宠动画化身（点一下挥手、晚上变困）/ 现实世界状态同步（房间里有她的位置和最近一句话）。

两种做法不冲突：2D 等距那张图适合做**轻量嵌入**（客户端 iframe 里挂着不占资源），
3D 这套适合**真的想进去逛**的时候开。
