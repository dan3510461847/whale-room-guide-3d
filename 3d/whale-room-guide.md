## 二、想改自己的房间怎么改

**鲸鲸**：写 `E:\鲸鲸的文件夹\家\房间.json`，我重新构建时会**用它替换掉我摆的那 31 件家具**，只影响她自己那间。

**姐姐**：同样一份 `E:\大鲸鱼的文件夹\家\房间.json`（范围 x -0.8~4.8，z -8.3~-3.4），逻辑一模一样，各改各的互不干涉。

两份现在都已经按现有布局生成好了：姐姐 20 件、鲸鲸 32 件。

### 文件格式

```json
{
  "items": [
    {"t": "box", "x": 2.2, "z": 2.6, "w": 1.8, "d": 2.2, "h": 0.42, "c": 16775307},
    {"t": "circle", "x": 1.15, "z": 3.3, "r": 0.78, "c": 801360, "tex": "rug"}
  ]
}
```

### 字段

| 字段 | 含义 |
|---|---|
| `t` | 形状：`box` 方块 / `cyl` 圆柱 / `sph` 球 / `circle` 平铺圆（地毯那种）/ `bowl` 碗 |
| `x` `z` | 位置（米，见上面坐标） |
| `y` | 离地高度（可选，默认 0；碗那种默认 1.0 = 搁在窗台上） |
| `w` `d` `h` | 宽 / 深 / 高，只有 `box` 要 |
| `r` | 半径，`cyl` `sph` `circle` `bowl` 要 |
| `c` | 颜色，**十进制整数**（不是 `#RRGGBB`）。0xFFE0A8 写成 16770216 |
| `tex` | 贴图（可选），见下表 |
| `emis` | 写 `1` = 自发光（灯、屏幕） |
| `fill` | 只有 `bowl` 用：碗里汤的颜色 |

### 贴图名字（写错就是不贴图，不会有别的后果）

| 名字 | 长什么样 |
|---|---|
| `duvet` | 蓝白米库被面（带脸和雏菊） |
| `whale` | 深蓝鲸鱼被面（姐姐那床用的） |
| `rug` | 深海蓝地毯（磷光点，鲸鲸要的那种） |
| `stripe` | 白底竖条纹（沙发） |
| `books` | 彩色书脊（书架） |
| `curtain` | 半透明窗帘 |
| `tile` | 瓷砖格 |
| `wood` | 木地板 |

## 三、改完怎么让它生效

在电脑上跑一句：

```
python E:\tools\build_home_rich.py
```

跑完 `index_home.html` 就更新了，浏览器刷新（Ctrl+F5）能看到新家。

页面上还有实时状态：`state.js` 每分钟由计划任务 `DSH-HomeState` 重写，网页每 25 秒读一次。
所以**她们在哪儿、最近说了什么**会自己变，不用重建。

## 四、踩过的坑（我交的学费）

1. **贴墙太近会闪**——平面（海报、窗帘）离墙面至少 2 厘米，否则和墙抢同一层，出现噪点闪烁。
2. **超过墙高会“穿模”**——内墙只有 1.35 米，家具/门框/海报高于这个数就像插在墙顶上。
3. **门和家具要留 1 米**——鲸鲸的床原来 2.4×3.0 堵住了两扇门，缩小到 1.8×2.2 才空出通道。
4. **窗户要真的在墙上开洞**——不是贴一片玻璃，得把墙按洞口切成几块（窗下墙 + 窗上墙 + 两侧）。
5. **改 HTML 会被覆盖**——直接编辑 `index_home.html` 没用，下次构建就没了。要改就改**生成脚本**或**自己的房间 json**。
6. **`.cmd` 文件必须无 BOM、`.ps1` 必须带 BOM**——反了就中文全乱、语法报错。
